# Folvella

Pinterest-driven Tier-1 lifestyle publishing site.

## Public site
A premium lifestyle magazine focused on food, home, beauty, fashion, DIY and seasonal content. Public pages never expose trend scores or Pinterest research.

## Private operations
`studio.html` is a noindex publishing workspace containing Pin briefs, boards, hooks and target URLs. It is hidden from public navigation but is not authentication-protected yet.

## Publishing model
Pinterest trend research → editorial article → Pin creative → article traffic → ads / affiliate → related-content recirculation.

Built for GitHub Pages.
