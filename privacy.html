Privacy

Updated October 4, 2026

The current website

InspoMint is a static website hosted on GitHub Pages. We do not currently operate user accounts, a newsletter signup database, advertising tags or a third-party analytics script. The on-page search filters article titles in your browser; it does not send your search words to a InspoMint search server.

Hosting and local assets

Your browser requests page files and original image assets from the hosting service. GitHub may process technical request information as the hosting provider. InspoMint does not control GitHub’s platform logs. Our current site code does not set tracking cookies or store an advertising profile.

External services

Save to Pinterest opens Pinterest only when you choose the button. Pinterest handles activity on its own service. The RSS feed is a public file that your chosen reader can request. Feedback links open GitHub, where your account and any submitted issue are handled by that service. Public feedback should not include private information.

Updates and questions

This notice describes the features currently installed. It will need revision before adding analytics, ads, accounts, email collection or other data-processing features. For a question about the site, use the feedback route on the contact page.
